# Privacy Policy for WA Group Extractor

**Last updated: October 2026**

### 1. Overview
WA Group Extractor ("the Extension") is a browser extension designed to help users extract public group participant phone numbers and names from WhatsApp Web into clipboard or CSV format.

### 2. Data Collection and Storage
- **No Personal Data Collected:** WA Group Extractor does not collect, track, log, or store any personal information, phone numbers, contact names, or chat content on any external servers.
- **Local Processing Only:** All data extraction, parsing, and formatting processes are performed 100% locally on the user's computer within the browser runtime.
- **No Third-Party Transmission:** Extracted data is never transmitted across the internet to any developer, third party, or analytics service.

### 3. Permissions Used
- **`activeTab`**: Used only to interact with the currently active tab when the user explicitly clicks the extension popup.
- **`scripting`**: Used strictly to read the visible/virtualized participant DOM elements in WhatsApp Web and perform auto-scrolling to capture the full participant list.
